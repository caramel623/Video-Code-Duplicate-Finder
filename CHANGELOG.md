# Changelog

## 0.0.1 - Test Release

Initial Windows 11 test release of Video Code Duplicate Finder.

- Video code scanning and duplicate-group results.
- Detailed video browser and asynchronous thumbnail preview mode.
- Optional safe folder deletion with recycle-bin default and two-step confirmation.
- FFmpeg/ffprobe path selection in Settings; FFmpeg remains a separate third-party dependency.
- MIT-licensed application source with pytest coverage for safety-critical deletion behavior.
